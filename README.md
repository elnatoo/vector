# V.E.C.T.O.R. (Versatile Entity of Communications, Technology Operations & Resources)
V.E.C.T.O.R. is an automated multi-purpose bot for Discord. 
V.E.C.T.O.R. is a playful and interactive Discord bot designed to engage users with witty replies, occasional pranks, and quirky status messages.
It adds personality to your server with fun responses and friendly automation.

## Features
- Responds with randomized greetings and messages
- Uses “STATUS:” tags with random activities for flavor
- Frequently uses the "~bzzt~" sound effect in messages
- Makes one hell of a latte! (Not really, but maybe one day)
